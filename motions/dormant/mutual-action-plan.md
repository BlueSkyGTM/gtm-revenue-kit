# Mutual action plan

**Activate when:** sales cycles run weeks to months with named milestones both sides must hit —
security review, data migration, board approval.

**Method:** a single shared document — milestones, an owner per milestone (theirs and ours), a
date per milestone, and the go-live date worked *backwards* from. The plan is mutual or it is
nothing: if the buyer will not co-own dates, that is qualification signal, not paperwork
friction.

**Output:** one per active deal in `accounts/<slug>/outputs/`; the dates set the deal's next
touch in the CRM.
