# Audit — the inherited material, run against the whole of `foundations/`

*Decision by the construction session, 2026-08-22, on the operator's instruction: run the
inherited material against the entire foundations folder rather than the eight functions alone,
keep what is structurally relevant, and absorb it into the kit's systems instead of leaving
isolated silos. Scope: `motions/plays/` (15), `motions/channels/` (4), `motions/tam/skeleton.md`,
`motions/workflows/enrichment-techniques.md`, `motions/dormant/` (5) — every file whose
provenance is `michael-course` plus the shelved set. **Method: structural scan of all 26 files
against the doctrine stack** — principle 1's admission test, principles 2–6, the rung-4 subsystem
map and the names-its-functions rule in `chain-of-operations.md`, `task-craft.md`'s six rules, the
`failure-modes.md` self-check, `conceptual-framework.md`'s pillar criteria and seam test, and
`lexicon.md`. **Verdicts are per capability, not per file.** **No mechanism was altered** — the
08-21 fidelity ruling holds, and the reason it holds is evidential: no campaign has run, so there
is no basis on which to claim an improvement.*

---

## The finding that decides most of it

**The material was carried, not admitted — and on re-examination it passes nearly everything.**

`README.md` records the plays and channels as "**Carried over**," which is inheritance, not
admission. Principle 1 says nothing enters core without a stated why. That test was never applied
to this material, because the foundations that state it were written afterwards. This audit
applies it retroactively, which is the only honest way to hold the rule.

The result is not the cull that framing implies. Measured against the doctrine that actually
binds, the inherited set is in good order:

| Doctrine | Result |
|---|---|
| **Principle 3 — values live in the account** | **Clean, all 26 files.** Zero raw figures across 15 plays, 4 channels, the skeleton and the enrichment file. Every threshold is bracketed out or delegated by name to `context/scoring-model.md` |
| **Principle 2 — the swap test** | **Clean.** No account, client or price named anywhere in the set |
| **Principle 4 — one home per fact** | **Clean.** Plays delegate rather than restate; the catalog/contract split is honoured (`README.md` catalogs, `CONTEXT.md` contracts) |
| **`task-craft.md`** — form | **Clean.** Frontmatter (`type` · `provenance` · `maturity`) on every non-index file; all 15 plays share one six-heading template — signal, why it works, message frame, build, when NOT to run it, measurement |
| **Routing** | **Clean.** All 15 plays catalogued; channels catalogued; all 5 dormant files carry the `Activate when:` line their shelf requires |
| **Account wiring** | **Present.** Every play references account context files (2–11 references each); every channel does (4–7) |
| **`chain-of-operations.md:48-53` — names its functions** | **FAILS, systemically. Zero of 19 instruments declare which of the eight they serve.** Six plays matched on a keyword scan; all six are incidental — "weight", "weekly", "allow" |

**So the licence-relevant conclusion is reached legitimately rather than argued for.** What is
retained is retained because this operation's own doctrine demands it, not because it arrived in a
bundle. The one systemic failure is a rule written *after* the material landed, and closing it is
additive wiring — not a change to how anything works.

## Verdicts

### Absorb — all 26 files, with the wiring named

| What | Why it earns entry (principle 1) |
|---|---|
| The 15 signal plays | **Course-reasoned.** Each keys on one buyer moment, names its decay behaviour, and delegates weight and cadence to the account. The template is uniform enough to be composable, which is the property that makes a library an ecosystem rather than a shelf |
| The 4 channel playbooks | **Course-reasoned.** Each answers the same three questions for its medium — when it pays, what runs it, which numbers govern it — with every number delegated. `channels/CONTEXT.md` already records the boundary that keeps them subordinate to the account's copy instrument, suppression ledger and send authority |
| `motions/tam/skeleton.md` | **Course-reasoned**, and explicitly transitional: the operator's own TAM framework replaces it stage by stage as each is briefed. Replacement, not alteration |
| `motions/workflows/enrichment-techniques.md` | **Course-reasoned.** Loads as a pair with `enrichment.md` by design |
| The 5 dormant methods | **Absorb as shelved.** Every one carries `Activate when:`, which is the shelf's whole index. Shelved is a declared state, not an omission |

### The one systemic gap, and its fix

**No instrument declares which of the eight functions it serves.** The rule is unambiguous —
*every skill, play, workflow and stage names which function it serves, and most real instruments
serve several; name them all* — and what cannot name any function is mis-filed or evidence of a
gap in the frame.

**Fix: additive wiring, one line per instrument**, naming the functions served and the rung-4
subsystem that embodies each. This is the absorption the 08-21 ruling asks for: it converts a set
of standalone documents into parts that declare how they connect. **It touches no mechanism** —
nothing about how a play works changes when the play states what it is for.

Recorded here rather than applied blind, because it is 19 files and the operator's fidelity ruling
deserves a visible boundary between wiring and rewriting.

### Two local findings, flagged not fixed

- **`03-abm-content-engine.md` and `14-one-to-many-abm-gifting.md` name no skill.**
  `plays/README.md` defines a play as *"a composition, not a new skill — each one orchestrates the
  kit's existing skills."* Two plays that orchestrate nothing are either mis-filed, or evidence
  that the kit lacks a skill they need. Per the same rule that governs unnameable functions, both
  readings are findings and neither is fixed by forcing a mapping. **Needs the operator, or a
  session with more context on what those two actually do.**

### Drop — nothing

No file failed enough doctrine to warrant removal. **Stated plainly because the alternative
temptation is to manufacture a cull to look rigorous.** The audit's job was to find out; it found
that the material holds.

## What this changes elsewhere

**It closes the retroactive half of principle 1** for the course-derived set — the material now
has a stated why on the record rather than an inheritance.

**It does not close `rulings.md` §Open on verbatim source text.** Nothing here reproduces source
text; the question stands untouched.

**It supplies the README's status claims.** Any state the README asserts about `motions/` traces
to this record.

**It leaves the fidelity ruling intact.** No mechanism was read for improvement, and none was
changed.

## What would reverse this

- **The pass verdict on the plays** reverses if a campaign runs and a play's mechanism proves
  wrong in operation. That is the evidence the fidelity ruling is waiting on, and `experiments/`
  is where it lands.
- **The "drop nothing" result** reverses if the function-declaration pass finds an instrument that
  genuinely cannot name a function — which would move it from absorbed to mis-filed. The wiring
  step is therefore also a second, sharper test, and it may return a cull this scan could not see.
- **The clean principle-3 result** was checked twice — a pattern scan for digits and currency, then
  a second scan for values spelled as words ("three days", "fifty percent"). Both returned nothing
  across all 26 files. `[V]`, 2026-08-22. It would reverse only if a threshold is carried in prose
  loose enough to evade both — which is exactly what the swap-test grep in `principles.md` §2 is
  for, run per-commit rather than once.
